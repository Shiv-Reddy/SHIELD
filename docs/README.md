which four to read and what the rest are for.

| File | What it is | Who for |

| [HOW_IT_WORKS.md](./HOW_IT_WORKS.md) | The whole project in plain words, no jargon | Everyone. Start here |

**Why nothing was deleted.** These files reference each other about 380 times.
Removing or moving them breaks those links, and the record of *why* a choice was
made is the most useful thing here when someone challenges a decision. The
problem was never that there are too many files — it was that there was no page
telling you which ones matter. This is that page.
