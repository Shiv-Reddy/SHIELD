    Controls in place

    ControlHow Shield does itWhere to check it
    Data minimisation Private data is hidden on the employee's own device. Only the redacted page ever reaches the AI. Every request is searched for anything flagged before it is sent, and refused if one is found
    Purpose limitation The AI can only click, type or scroll. Anything else is rejected on the server and again on the device. Action allowlist, checked twice
    One decision at a time Approve, pay, submit and similar actions end the task. A second one needs a new request from a person. The activity log below
    No retention The server answers and forgets. Its logs hold a request ID and a time, never page content. Server logs
    Transparency The exact last message sent to the AI can be opened and read. "What was sent" in the Shield panel
    Accountability This report and its data file hold counts only: no values, no page text, no web addresses. "Download data" above

    These controls support the reasonable security safeguards the Digital Personal Data Protection Act, 2023 expects of organisations handling personal data. This report supports a compliance review. It is not a certification.
