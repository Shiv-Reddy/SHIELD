How hard Shield looks

Shield always hides what it is sure about. This sets the smallest image it will bother reading text out of — which is the one part of detection that was ever a judgement call rather than a rule.

Where redacted context is sent

Only sanitised context ever reaches this address. Change it to point at a different backend — a hosted one, or a second machine on your network.

Your organisation

This laptop can report its counts to your organisation's dashboard on the same server: how many items of each kind were hidden, and whether anything was sent. Never page content, field values or web addresses.

Open the organisation dashboard

What runs, and where

Shield prefers your graphics hardware and falls back to the CPU on its own. These pin that choice, so the fallback can be exercised on a machine where it would otherwise never run — which is the only honest way to know it still works.

Changing either rebuilds the loaded model, which takes about a second on Chrome and about ten on Firefox.

Before Shield acts

Neither of these is what keeps your data on this device. That is enforced whether they are on or off — see the privacy note below.

What is not configurable, and why

There is no setting that makes Shield hide less than it does now. Redaction is not gated on a confidence threshold, and adding one to make this page look richer would turn a guarantee into a preference. When Shield is unsure whether something is sensitive, it hides it.
